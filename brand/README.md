# Studio Mist visual system

Studio Mist work uses one geometric, architectural system across repository graphics and future product materials.

## Typography

Use **Kumbh Sans** with the YOPQ axis at 300. Structure comes from weight, scale, spacing and alignment rather than a second typeface.

- Display: 700 to 800
- Labels: 550 to 650, uppercase, generously tracked
- Body: 400 to 500
- Numeric data: 650 to 750

The bundled font is distributed under the SIL Open Font License in [`fonts/OFL.txt`](fonts/OFL.txt).

## Palette

Use these seven brand colours, plus white for primary headline text and small high-contrast labels or icons on colour blocks:

| Token | Value | Role |
|---|---|---|
| Pink | `#f493bf` | soft accent and secondary fields |
| Cyan | `#00a0bc` | signal, link and active detail |
| Navy | `#1c3a6b` | primary field and strong text |
| Periwinkle | `#b7bfd6` | light field, grid and text |
| Teal | `#027f86` | secondary structure |
| Deep teal | `#0c4a56` | alternate dark field |
| Hot pink | `#e0218a` | primary accent and focal signal |
| White | `#ffffff` | primary headlines and high-contrast labels or icons |

## Composition

- Use an architectural grid with visible alignment, fine rules and measured spacing.
- Prefer modular diagrams, frames and structural line work over decorative illustration.
- Keep corners square unless a functional object requires a small radius.
- Use one dominant dark field, white primary headlines, one light structural colour and one or two signal accents.
- Do not use gradients, drop shadows, photography or colours outside the palette.
- Keep copy short and let scale create hierarchy.

Repository social previews are 1280 by 640 pixels and share the same left-hand title system, Studio Mist label and right-hand technical diagram.
